CHATBOT SETUP (Grok / xAI or Groq) - Hassan Diesel Engineering website

The website chat uses a secure serverless backend (/api/chat). The code now automatically supports BOTH Grok (xAI) and Groq:

---------------------------------------------------------
OPTION A: Using Grok (from xAI - Elon Musk's platform)
---------------------------------------------------------
1. Get your API key from https://console.x.ai (starts with "xai-").
2. In Vercel, go to your Project > Settings > Environment Variables.
3. Add:
     GROK_API_KEY = your xai-... key  (or XAI_API_KEY)
     GROK_MODEL   = grok-2-latest     (optional, defaults to grok-2-latest)

---------------------------------------------------------
OPTION B: Using Groq (GroqCloud - Ultra fast / Free tier)
---------------------------------------------------------
1. Get your free API key from https://console.groq.com (starts with "gsk_").
2. In Vercel, go to your Project > Settings > Environment Variables.
3. Add:
     GROQ_API_KEY = your gsk_... key
     GROQ_MODEL   = llama-3.3-70b-versatile  (optional)

---------------------------------------------------------
CRITICAL STEPS TO MAKE IT WORK:
---------------------------------------------------------
1. Deploy the entire folder to Vercel (both index.html AND the /api folder).
2. After adding or editing Environment Variables in Vercel, you MUST REDEPLOY:
   - Go to Vercel > Deployments
   - Click the three dots (...) on your latest deployment
   - Click "Redeploy"
   (Vercel does NOT inject new environment variables into existing deployments without a redeploy!)
3. Test on your live Vercel URL (e.g. https://your-project.vercel.app):
   - The chatbot calls /api/chat. It will NOT work by opening index.html directly from your computer (file:///) or using Live Server, because static browsers cannot run the serverless API.
4. If there is an issue, press F12 (Inspect) > Console in Chrome to see the exact error message.
